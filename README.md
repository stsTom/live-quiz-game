## How to test

1. Clone this repository
2. Install dependencies: `npm install`
3. Start in dev mode: `npm run dev`
5. Open `http://localhost:5173` in two browser tabs
6. In one tab — register and create a game (host)
7. In the other tab — register and join the game using the room code
8. Host starts the game, player answers questions
9. Verify scores, results, and final scoreboard
